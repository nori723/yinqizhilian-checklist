# 银企直联材料清单 · HTML 工具使用说明

**当前版本：v1.1**（2026-09-03，整合内容审查 + 评审意见第一轮改造）

## 这是什么

把《银企直联材料清单.xlsx》编译成**手机端单文件网页**（`银企直联材料清单.html`），按「先懂概念 → 再选业务 → 再看材料」组织，含行内/客户双视图、收单勾选核对、客户版清单导出。行内专用，请勿外传。

## 手机上怎么用

1. 把 `银企直联材料清单.html` 传到手机（只传这一个文件）。
2. **用手机「浏览器」或 Chrome 打开**（不要用"HTML 查看器"，它不执行脚本；微信内点「···」→「用浏览器打开」）。
3. 可选：浏览器菜单 →「添加到主屏幕」当 App 用。完全离线可用。

## 核心功能速查

| 功能 | 在哪里 | 说明 |
|---|---|---|
| 场景族导航 | 底部「业务场景」 | 5 大业务族（首次签约/成员调整/操作员与凭证/开通新功能/特殊事项），场景卡带 ⚠ 待确认角标 |
| 两步决策器 | 首页 | 回答"是否已开通→想做什么"直达场景 |
| 全局搜索 | 顶部输入框 | 可搜材料名、填写要点、盖章要点、注意事项；支持快捷词（盖章/份数/异地/多久/收费）；不区分大小写 |
| **行内/客户视图** | 顶栏「客户版/行内版」按钮 | 客户视图隐藏行内话术、客户经理要点、数据溯源、待确认与审查标注，可直接展示给客户；选择会被记住 |
| **复制客户版清单** | 场景页「📋 复制客户版清单」 | 生成不含任何行内信息的纯文本，粘贴到微信直接发客户 |
| **收单勾选核对** | 场景页材料卡勾选框 | 逐项打勾，显示「收单核对 x/n」，进度自动记忆，可一键清除 |
| 打印/存 PDF | 浏览器菜单 → 打印 | 已配打印样式（自动隐藏导航、展开全部明细） |
| 大字模式 | 顶栏「A+」 | 适合给客户/年长经办人看 |
| 材料总览 | 底部「材料总览」 | 原表 9 场景矩阵 + 自动补充的新增司库/薪资代发/文件证书 3 场景矩阵；列头和 ✓ 可点击跳转 |
| 待确认口径 | 场景页「⚠ N 条待确认」 | 原表自身口径不一致之处，逐条列出，原文未改动、按明细表口径执行 |
| 审查标注 | 场景页虚线黄框 | 内容审查发现的矛盾点挂在原文旁（仅行内视图） |
| 数据溯源 | 每项材料「数据溯源」 | 来源 Sheet + 行号（仅行内视图） |

## 目录结构与更新机制

```
银企直联业务\
├── 银企直联材料清单.xlsx      ← 唯一数据源（改这里）
├── 银企直联材料清单.html      ← 生成产物（不要手改）
├── 银企直联材料清单_评审意见.md ← 评审记录
└── html工具\
    ├── build.py               ← 构建脚本
    ├── template.html          ← 页面模板（改样式/交互才需要动）
    ├── mapping.json           ← 人工整理层（场景分组/决策树/审查标注/待确认清单）
    ├── data_standardized.json ← 中间产物（含溯源字段与归档表，可追溯）
    ├── 数据校验报告.md         ← 自动校验（每次构建生成）
    ├── 内容审查报告.md         ← 内容审查结论（矛盾清单/合并建议/评审落实情况）
    └── 使用说明.md            ← 本文件
```

**Excel 更新两步**：覆盖 xlsx → 在 html工具 目录运行 `python build.py`。

**构建后必看两个报告**：
- 《数据校验报告.md》：遗漏/新增/名称不一致/未映射必须为 0；「待确认」为原表自身口径差异，逐条列出。
- 《内容审查报告.md》：矛盾清单（C1-C8）、场景合并建议（M1-M4）、歧义待明确（Q1-Q4）、评审意见落实情况。

## 常见调整在哪里改

| 想改什么 | 改哪里 | 之后 |
|---|---|---|
| 业务材料/份数/盖章变了 | `银企直联材料清单.xlsx` | 重跑 build.py |
| 场景分组/图标/决策器 | `mapping.json` 的 `scene_groups`/`scene_icons`/`decision` | 重跑 build.py |
| 审查标注/待确认清单 | `mapping.json` 的 `annotations`/`scene_pending`/`audit` | 重跑 build.py |
| 副标题改写（"什么时候用"） | `mapping.json` 的 `subtitle_fix` | 重跑 build.py |
| 页面样式、配色、交互 | `template.html` | 重跑 build.py |

## 安全边界（已内置，改动时请保持）

- 零外部依赖：无 CDN/在线字体/图片/iframe/任何网络请求，断网完整可用。
- 数据内嵌 JSON；草稿表与目录行不再内嵌进 HTML（仍在 data_standardized.json 供追溯）。
- 构建时自动安全扫描，发现外链会写入校验报告。

## 质量保障（当前版本已验证）

- 16/16 工作表读取；62 项材料 0 遗漏 / 0 新增 / 0 名称不一致；端到端比对（HTML 内嵌数据 ↔ Excel 逐行）一致。
- 知识库/目录/材料总览的数量标称与场景实际数量自动比对，冲突以红色「实际 X 项」呈现并计入待确认。
- 390px 手机视口实测：场景族 UI、决策器、场景详情（待确认块/审查标注/勾选）、客户视图切换、客户版导出、搜索（含大小写）、矩阵补充表、大字模式。
- 客户版导出文本按审查结论 C1/C2 将错误序号指代替换为表名指代（页面原文不动）。
